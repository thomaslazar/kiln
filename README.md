# Kiln

An ad-free 8x8 block puzzle for phones. Drag pieces onto the board; full rows and
columns clear. Levels are generated endlessly, every set of pieces you get can be placed,
and failing a level makes the retry a little easier.

Open `index.html` in a browser or serve the folder with any static server.
`node tools/sim.mjs` runs the balance bot. Developer notes are in `CLAUDE.md`.
