# Endless Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An endless score mode next to the levels: empty board, flat `d` = 0.75, no target, best score and best combo, switching in the menu, a one-time welcome card.

**Architecture:** `src/core.js` gets a pure endless state (`type:'endless'`) that the existing `deal`, `resolveMove` and `clearCells` run on unchanged. `src/ui.js` keeps two states, `L` (levels, `kiln-v2`, unchanged format) and `E` (endless, `kiln-endless`), and points `S` at the live one by `mode` (`kiln-mode`). Level-only code branches on `S.type==='endless'`.

**Tech Stack:** Vanilla ES modules, `node --test`, no dependencies.

**Spec:** `docs/superpowers/specs/2026-11-22-endless-design.md`

## Global Constraints

- No dependencies, no build step. Rules pure in `src/core.js` (no DOM, no storage). No `Math.random` in `src/`; the UI seeds a run with `crypto.getRandomValues`.
- All visible text in `lang/en.json` and `lang/de.json` (same keys, same placeholders, no em-dashes, typographic apostrophes ’). `tests/lang.test.mjs` requires `src/ui.js` to use exactly the `en.json` keys.
- `deal()` keeps its `solvable` check. Endless `d` = 0.75, never changed during a run.
- The level save format in `kiln-v2` does not change; nothing here may alter level progress.
- Compact, terse JS matching the surrounding style. Sentence case copy.
- Work on branch `feat/endless`. Run `node --test` after every task. Commit messages: Conventional Commits, no `Co-Authored-By` or "Generated with" lines.

## Review Focus

1. Switching modes mid-drag or mid-clear animation: menu is blocked while `busy||drag` today; the switch must go through the menu only, so it stays blocked.
2. Flying gems or a pending `finish()` timeout from levels landing on the endless state after a switch: `flightGen++` on switch; switching is only possible when not `busy`.
3. A corrupt or old-version `kiln-endless`: falls back to a new run, keeps nothing broken, never touches `kiln-v2`. Test in Task 1 (`validEndless` rejects broken shapes).
4. "Easier retries" toggled while in Endless: must rebuild only `L`'s goal and never call `won` or `afterMove` on `E`.
5. `localStorage` unavailable (private mode): every read and write stays in `try/catch`; the game still plays, the welcome card may show again next launch.

  - `finishRun(E) -> E`: idempotent; first call sets `E.newBest = E.score > E.best`, `E.newCombo = E.top > E.bestCombo`, raises `best`/`bestCombo` to the run's values, sets `over = true`. Later calls change nothing.
  - `validEndless(s) -> boolean`.
  - `won(E)` is `false`; `activeGems(E)` is `[]`; `comboContinue(E, m)` stays false (it checks `S.type==='score'`).
  - `resolveMove` keeps `E.top = max(E.top, E.combo)` when `S.type==='endless'`.

```js
import test from 'node:test';
import assert from 'node:assert/strict';
import { startEndless, finishRun, validEndless, won, activeGems, solvable, occOf, resolveMove, SHAPES, SINGLE } from '../src/core.js';

test('a run starts empty at d 0.75 with a fair tray and no gems', () => {
  for (let seed = 1; seed <= 20; seed++) {
    const E = startEndless(seed);
    assert.equal(E.type, 'endless'); assert.equal(E.d, 0.75);
    assert.ok(E.color.every(v => v === 0) && E.gem.every(v => v === 0));
    assert.ok(solvable(occOf(E.color), E.tray.map(p => p.s), 25000));
    assert.ok(E.tray.every(p => p.g.every(g => g === 0)));
    assert.ok(Number.isInteger(E.chapter) && E.chapter >= 1 && E.chapter <= 50);
    assert.ok(['normal', 'mono', 'pattern'].includes(E.look.mode));
    assert.equal(E.look.pattern === null, E.look.mode !== 'pattern');
    assert.equal(won(E), false); assert.deepEqual(activeGems(E), []);
  }
});
test('same seed, same run; bests carry over', () => {
  assert.deepEqual(startEndless(7), startEndless(7));
  const E = startEndless(8, 1234, 9); assert.equal(E.best, 1234); assert.equal(E.bestCombo, 9);
});
test('looks vary across runs', () => {
  const modes = new Set(), chapters = new Set();
  for (let s = 1; s <= 300; s++) { const E = startEndless(s); modes.add(E.look.mode); chapters.add(E.chapter); }
  assert.equal(modes.size, 3); assert.ok(chapters.size > 30);
});
test('resolveMove tracks the top combo of the run', () => {
  const E = startEndless(3);
  for (let c = 0; c < 7; c++) E.color[c] = 1;              // row 0 misses one cell
  E.tray[0] = { s: SINGLE, c: 2, g: [0] };
  resolveMove(E, 0, 0, 7);
  assert.equal(E.combo, 1); assert.equal(E.top, 1);
});
test('finishRun raises bests once and flags them', () => {
  const E = startEndless(4, 100, 5); E.score = 150; E.top = 3;
  finishRun(E);
  assert.equal(E.best, 150); assert.equal(E.bestCombo, 5); assert.equal(E.newBest, true); assert.equal(E.newCombo, false); assert.equal(E.over, true);
  E.score = 999; finishRun(E); assert.equal(E.best, 150);
});
test('validEndless accepts a fresh or finished run and rejects broken ones', () => {
  const E = startEndless(5);
  assert.ok(validEndless(JSON.parse(JSON.stringify(E))));
  assert.ok(validEndless(JSON.parse(JSON.stringify(finishRun(startEndless(6))))));
  for (const bad of [null, {}, { ...E, type: 'score' }, { ...E, color: [] }, { ...E, best: 'x' }, { ...E, chapter: 0 },
    { ...E, look: { mode: 'odd', pattern: null } }, { ...E, tray: [null, null] }, { ...E, tray: [{ s: SHAPES.length, c: 1, g: [] }, null, null] }])
    assert.equal(validEndless(bad), false);
});
```
