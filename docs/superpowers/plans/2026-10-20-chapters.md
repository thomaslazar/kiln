# Chapters Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Group levels into 30–40-level chapters with a difficulty dip and ramp, a generated look per chapter (colours, tile style, gem symbols and style), and per-level one-colour and pattern looks.

**Architecture:** Chapter maths and level looks are pure functions in `src/core.js`. A new pure module `src/theme.js` generates each chapter's look as data plus SVG strings. `src/ui.js` applies the theme as CSS custom properties, draws gems as SVG everywhere, and picks tile colours per look mode. Saves do not change: everything is derived from the level number.

**Tech Stack:** Vanilla ES modules, CSS (OKLCH, `color-mix`), Node 26 `node --test`. No dependencies.

**Spec:** `docs/superpowers/specs/2026-10-20-chapters-design.md`

## Global Constraints

- No frameworks, no build step, no dependencies, no `package.json`.
- Deterministic: derive from `hash`/`mulberry32` in `src/core.js`; no `Math.random` in `src/`.
- `src/core.js` and `src/theme.js` stay pure (no DOM, no storage).
- `deal()` and its `solvable` check are untouched; looks never change rules.
- All visible text in `lang/en.json` and `lang/de.json` via `t('key')`; `tests/lang.test.mjs` must keep passing.
- Light and dark mode via `prefers-color-scheme`, including switching while the game is open.
- Copy: sentence case, no em-dashes. Compact, terse JS like the existing code.
- Test command: `node --test` (not `node --test tests/`).
- Commits: Conventional Commits, lowercase imperative. Never add `Co-Authored-By:` or "Generated with" lines.

## Shared names (all tasks use these)

- `chapterOf(level) -> {n, start, length}` (core). Chapter 1: start 1, length 40. Chapter k ≥ 2: length `30 + hash(k) % 11`.
- `difficulty(level, fails)` (core): chapter-aware base, global wave, easing unchanged.
- `levelLook(level) -> {mode: 'normal'|'mono'|'pattern', pattern: null|'rows'|'columns'|'diagonal'|'rings'}` (core).
- `chapterTheme(n)` (theme.js) returns:
  `{n, hue, light, dark, tiles: {light: [5], dark: [5]}, tileHues: [5], gems: {light: [5], dark: [5]}, gemHues: [5], symbols: [5], style, rad, gloss}`
  where `light`/`dark` are `{bg, ink, muted, board, well, track, sheet, accent, neutral}` CSS colour strings.
- `SYMBOLS` (theme.js): the 13 name → path entries from the spec appendix.
- `symbolSVG(name, style, colour, id) -> string` (theme.js): one `<svg viewBox="0 0 24 24">` for a gem.
- `hueGap(a, b)`, `safeTile(theme, tile, gem) -> tile`, `monoTile(theme, gems) -> tile`, `patternPos(kind, r, c) -> 0..1`, `patternColour(theme, scheme, pos) -> css` (theme.js). Tile and gem indices here are 0..4; board values 1..5 map to index − 1.

**Files:** Modify `src/core.js`. Test: `tests/chapters.test.mjs` (new).

**Interfaces:** Produces `chapterOf`, new `difficulty`, `levelLook` (see Shared names).

Rules (spec): chapter 1 keeps today's base `min(.75, (level-1)/50)`. Chapter k ≥ 2: `floor = (10 + hash(k) % 6 - 1) / 50`; `p = (level - start) / length`; `base = floor + (.75 - floor) * min(1, p / .7)`. The wave `[0,.06,.12,.18,-.08][(level-1)%5]` and easing `-.18*max(0, fails-3)`, clamp 0..1, stay. `levelLook`: 70/15/15 from `hash(level*…)`, never two non-normal levels in a row (cached iteratively like `levelType`), level 1 and 2 normal; pattern kind from the hash.

```js
import test from 'node:test';
import assert from 'node:assert/strict';
import { chapterOf, difficulty, levelLook } from '../src/core.js';

test('chapter 1 is levels 1-40, later chapters 30-40 levels back to back', () => {
  assert.deepEqual(chapterOf(1), { n: 1, start: 1, length: 40 });
  assert.deepEqual(chapterOf(40), { n: 1, start: 1, length: 40 });
  assert.equal(chapterOf(41).n, 2); assert.equal(chapterOf(41).start, 41);
  let prev = chapterOf(41);
  for (let lv = 41; lv <= 2000; lv++) {
    const c = chapterOf(lv);
    assert.ok(c.length >= 30 && c.length <= 40);
    assert.ok(lv >= c.start && lv < c.start + c.length);
    if (c.n !== prev.n) { assert.equal(c.n, prev.n + 1); assert.equal(c.start, prev.start + prev.length); }
    prev = c;
  }
});
test('chapter 1 difficulty is unchanged', () => {
  for (let lv = 1; lv <= 40; lv++) {
    const base = Math.min(.75, (lv - 1) / 50), saw = [0, .06, .12, .18, -.08][(lv - 1) % 5];
    assert.ok(Math.abs(difficulty(lv, 0) - Math.max(0, Math.min(1, base + saw))) < 1e-9, `level ${lv}`);
  }
});
test('later chapters dip to the level 10-15 floor and ramp to the ceiling', () => {
  const base = lv => difficulty(lv, 0) - [0, .06, .12, .18, -.08][(lv - 1) % 5];
  for (let lv = 41; lv <= 1500; lv++) {
    const c = chapterOf(lv);
    if (lv === c.start) assert.ok(base(lv) >= 9 / 50 - 1e-9 && base(lv) <= 14 / 50 + 1e-9, `start ${lv}: ${base(lv)}`);
    if (lv - c.start >= Math.ceil(c.length * .7)) assert.ok(Math.abs(base(lv) - .75) < 1e-9, `peak ${lv}`);
    if (lv > c.start) assert.ok(base(lv) >= base(lv - 1) - 1e-9, `no drop inside chapter at ${lv}`);
  }
});
test('easing from the 4th fail still works in later chapters', () => {
  assert.ok(Math.abs(difficulty(100, 4) - Math.max(0, difficulty(100, 0) - .18)) < 1e-9);
  assert.equal(difficulty(100, 3), difficulty(100, 0));
});
test('level looks: about 70/15/15, never two special looks in a row, stable', () => {
  const n = { normal: 0, mono: 0, pattern: 0 }, kinds = new Set();
  for (let lv = 1; lv <= 4000; lv++) {
    const L = levelLook(lv); n[L.mode]++;
    if (L.mode === 'pattern') { assert.ok(['rows', 'columns', 'diagonal', 'rings'].includes(L.pattern)); kinds.add(L.pattern); }
    else assert.equal(L.pattern, null);
    if (lv > 1) assert.ok(L.mode === 'normal' || levelLook(lv - 1).mode === 'normal', `two specials at ${lv}`);
  }
  assert.equal(levelLook(1).mode, 'normal'); assert.equal(levelLook(2).mode, 'normal');
  assert.ok(n.normal / 4000 > .64 && n.normal / 4000 < .76, JSON.stringify(n));
  assert.ok(n.mono / 4000 > .11 && n.pattern / 4000 > .11, JSON.stringify(n));
  assert.equal(kinds.size, 4);
  assert.deepEqual(levelLook(321), levelLook(321));
});
```

### Task 2: Pure theme generator

**Files:** Create `src/theme.js`. Test: `tests/theme.test.mjs` (new).

**Interfaces:** Consumes `hash`, `mulberry32` from `src/core.js` (export them if not exported). Produces everything listed under theme.js in Shared names.

Values (spec, verbatim):
- Chapter 1 (fixed): light `bg #E4E8E1, ink #1E2A2D, muted #5E6B68, board #C6CEC3, well #D7DDD3, track #CBD2C8, sheet #F2F4EF, accent #3B5FA0`; dark `bg #141C1F, ink #E2E8E4, muted #93A19D, board #0C1315, well #1C272B, track #26333A, sheet #1C2629, accent #5479C2`. Tiles light `#5E9E8F #3B5FA0 #C99530 #A2433C #77589A`, dark `#6DB3A3 #5479C2 #D9A63E #BD5148 #8F6CB5`; `tileHues [177, 261, 80, 27, 305]`. Gems light `#FF4D6D #4CC2FF #4BE08A #FFC83D #C792FF`, dark `#F23D5E #3DB0EE #3DCF78 #EDB52C #B67FF0`; `gemHues [15, 235, 154, 86, 305]`. Symbols `diamond, circle, triangle, star, hexagon`, style `matte`, rad `20%`, gloss `.42`. Neutral: light `#9AA39E`, dark `#56635F`.
- Chapters ≥ 2: as in the spec "Chapter look (generated)" section: `H`, scheme offsets, tile L `[.62,.52,.72,.47,.66]` (+.06 dark), C `.11..15`, surfaces, accent from tile 2's hue, rad from `20% 12% 30%`, gloss from `.42 .25 .55`, gem hues `H + offset + k*72` with `oklch(.84 .16 hue)` for both schemes, 5 symbols from the 13 without the look-alike pairs `circle/ring, circle/hexagon, ring/hexagon, drop/leaf`, style from `jewel matte line duotone glow`. Derived (builder's call, low chroma, readable): muted, track, sheet; neutral `oklch(.62 .02 H)` light, `oklch(.55 .02 H)` dark.
- `hueGap(a,b)`: smallest angle between hues (0..180). Similar = gap < 35.
- `safeTile(theme, tile, gem)`: `tile` if `hueGap(tileHues[tile], gemHues[gem]) >= 35`, else the tile index with gap ≥ 35 whose hue is closest to the original tile's hue; if none, the index with the largest gap to the gem.
- `monoTile(theme, gems)`: first tile index (in a seeded-by-`theme.n` order) not similar to any gem in `gems` (0..4 indices); if none, the one with the largest smallest gap.
- `patternPos(kind, r, c)`: rows `r/7`, columns `c/7`, diagonal `(r+c)/14`, rings `max(|r-3.5|, |c-3.5|)/3.5`, all clamped to 0..1.
- `patternColour(theme, scheme, pos)`: smooth mix through the 5 tile colours of `scheme` in index order: `color-mix(in oklch, A p%, B)` between neighbours.
- `symbolSVG(name, style, colour, id)`: strings for the five styles as described in the spec (jewel uses a `radialGradient` with the unique `id`). `colour` is any CSS colour (the UI passes `var(--gemN)`).

```js
import test from 'node:test';
import assert from 'node:assert/strict';
import { chapterTheme, SYMBOLS, symbolSVG, hueGap, safeTile, monoTile, patternPos, patternColour } from '../src/theme.js';

const ALIKE = [['circle', 'ring'], ['circle', 'hexagon'], ['ring', 'hexagon'], ['drop', 'leaf']];
test('chapter 1 keeps today’s look', () => {
  const t = chapterTheme(1);
  assert.deepEqual(t.symbols, ['diamond', 'circle', 'triangle', 'star', 'hexagon']);
  assert.equal(t.style, 'matte'); assert.equal(t.light.bg, '#E4E8E1'); assert.equal(t.tiles.dark[4], '#8F6CB5');
});
test('generated chapters are deterministic and well formed', () => {
  for (let n = 2; n <= 200; n++) {
    const t = chapterTheme(n);
    assert.deepEqual(t, chapterTheme(n));
    assert.equal(new Set(t.symbols).size, 5); t.symbols.forEach(s => assert.ok(SYMBOLS[s], s));
    assert.ok(!ALIKE.some(([a, b]) => t.symbols.includes(a) && t.symbols.includes(b)), `${n}: ${t.symbols}`);
    assert.ok(['jewel', 'matte', 'line', 'duotone', 'glow'].includes(t.style));
    for (const k of ['light', 'dark']) { assert.equal(t.tiles[k].length, 5); assert.equal(t.gems[k].length, 5);
      for (const v of Object.values(t[k])) assert.equal(typeof v, 'string'); }
    for (let a = 0; a < 5; a++) for (let b = a + 1; b < 5; b++) assert.ok(hueGap(t.gemHues[a], t.gemHues[b]) >= 70);
  }
  assert.equal(new Set([2, 3, 4, 5, 6, 7, 8, 9].map(n => chapterTheme(n).hue)).size > 4, true);
});
test('hue gap', () => { assert.equal(hueGap(350, 10), 20); assert.equal(hueGap(0, 180), 180); assert.equal(hueGap(90, 90), 0); });
test('a gem never sits on a similar tile', () => {
  for (let n = 1; n <= 120; n++) {
    const t = chapterTheme(n);
    for (let tile = 0; tile < 5; tile++) for (let gem = 0; gem < 5; gem++) {
      const s = safeTile(t, tile, gem), ok = [0, 1, 2, 3, 4].some(i => hueGap(t.tileHues[i], t.gemHues[gem]) >= 35);
      if (ok) assert.ok(hueGap(t.tileHues[s], t.gemHues[gem]) >= 35, `ch ${n} tile ${tile} gem ${gem}`);
      if (hueGap(t.tileHues[tile], t.gemHues[gem]) >= 35) assert.equal(s, tile);
    }
  }
  const c1 = chapterTheme(1); assert.notEqual(safeTile(c1, 4, 4), 4);   // purple tile under amethyst gem
});
test('one-colour pick avoids the goal’s gem hues', () => {
  for (let n = 1; n <= 120; n++) {
    const t = chapterTheme(n);
    for (const gems of [[0], [1, 3], [0, 2, 4], []]) {
      const m = monoTile(t, gems), ok = [0, 1, 2, 3, 4].some(i => gems.every(g => hueGap(t.tileHues[i], t.gemHues[g]) >= 35));
      assert.ok(m >= 0 && m <= 4); if (ok) assert.ok(gems.every(g => hueGap(t.tileHues[m], t.gemHues[g]) >= 35));
    }
  }
});
test('pattern positions and colours', () => {
  assert.equal(patternPos('rows', 0, 5), 0); assert.equal(patternPos('rows', 7, 0), 1);
  assert.equal(patternPos('columns', 3, 7), 1); assert.equal(patternPos('diagonal', 7, 7), 1);
  assert.equal(patternPos('rings', 3, 4), patternPos('rings', 4, 3)); assert.ok(patternPos('rings', 0, 0) === 1);
  const t = chapterTheme(9);
  assert.ok(patternColour(t, 'light', 0).includes(t.tiles.light[0]));
  assert.ok(patternColour(t, 'dark', 1).includes(t.tiles.dark[4]));
});
test('symbol SVGs for every style', () => {
  for (const style of ['jewel', 'matte', 'line', 'duotone', 'glow']) for (const s of Object.keys(SYMBOLS)) {
    const svg = symbolSVG(s, style, 'var(--gem1)', 'x1');

});
```

### Task 4: One-colour and pattern levels

Rules (spec): look mode and pattern kind from `levelLook(S.level)`. Pattern: board tiles use `patternColour(theme, scheme, patternPos(kind, r, c))`; a board tile carrying a gem uses `var(--g{safeTile(theme, nearest, gem-1)+1})` where `nearest` is the palette index closest to the cell's position (`round(pos * 4)`); pieces (tray, float, ghost, preview) use `var(--neutral)`. Normal: Task 3 behaviour.
